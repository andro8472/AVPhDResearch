# AVPhDResearch
AV Doctorate in Film Data Mining Research repository
Includes: 
- Data 
-- Raw - Corpora of Film scripts: Audio described and Screenplays (Downloaded externally)
-- Processed - Raw Data Processing and Data Preperation (Pre-analysis and Corpora Formation) and  Stoplists
- Src
-- Preperation (OCR Tools, Text Cleaners, File Converters)
-- Processing - Text tolenisation and processing (bi-tri-n-grams, frequency lists, early term extraction)
-- Analysis (categories creation, search tools for local grammar formation-investigation, summaries, sentiment analyser)
-- Visualisations (post-Analysis)
- Notebooks - For under development or POCs
- Test - Test Python scripts and POCs, alternate versions
- Docs - for documentation
- .gitignore - Items for Github to ignore
- requirements.txt - List of libraries (nltk, spacy, easyocr) and a how to guide
